# Zapper v3.1.8 — public downloads repository and version display

## One-time Vercel change

In Vercel → `zapper-prod` → Settings → Environment Variables, set:

```text
VITE_DESKTOP_DOWNLOAD_URL=https://github.com/shivanew-hadoop/zapper-downloads/releases/latest/download/Zapper-Setup-x64.exe
```

Save and redeploy Vercel once. Future releases do not require a Vercel change as long as the release asset remains `Zapper-Setup-x64.exe`.

## Public download repository

Use:

```text
https://github.com/shivanew-hadoop/zapper-downloads
```

Keep the source repository `zapper-prod` private. The downloads repository should contain no source code.

## Release process

1. Change `apps/desktop/package.json` version for the new release.
2. Run `npm run dist` from `apps/desktop`.
3. In `zapper-downloads`, create a GitHub Release with a matching tag, e.g. `v3.1.8`.
4. Upload the installer using the fixed asset filename `Zapper-Setup-x64.exe`.
5. Publish as a normal release.
6. Confirm the permanent latest URL downloads the new build.

## Overlay

The overlay reads the installed version from Electron using `app.getVersion()`. The displayed value therefore tracks `apps/desktop/package.json`. `Get latest` opens the permanent latest download URL from `apps/desktop/app-config.json`.
