# Zapper v1.0.13 — Live overlay scroll and no-flash safeguard

## Baseline and scope

Based **only** on the provided Zapper v1.0.12 source, which itself used the v1.0.7 application baseline. Only desktop display and native overlay-window control were changed. Existing web and API code, Meet English (UK) selectors, caption collector timing (240 ms stable interim / 2400 ms final timer), technology correction vocabulary, PIN, chat, session management, PDFs and Deepgram-off configuration are unchanged.

## Two user-facing changes

1. **Live captions stay in view.** Native `scroll` events generated by the overlay's own `scrollTop` changes no longer deactivate auto-follow. Manual upward scroll still pauses auto-follow so hosts can read previous captions. New caption chunks appear immediately on receipt; no new buffer, timer or network call was introduced.
2. **Displayed text remains fixed.** Once incoming words are rendered, their text nodes are never modified or removed on an interim revision or final caption event. Finalization only appends an unprinted suffix, avoiding previous remove-and-rebuild flashes. There is no 100-line limit or rebuild. New words are inserted as immutable per-update chunks to keep long meetings efficient.

**Native safeguard:** The quarter-second overlay guard no longer calls `moveTop()` repeatedly, which could flash the complete overlay. A temporary host caption-relay authorization failure no longer sends a fake 'host session stopped' event to the display; the authorized host's own Meet captions can continue. Confirmed End Session still closes the view.

## Verification

- `cd apps/desktop && npm run check` (including auto-follow, immutable text and 160-line retention test)
- `cd apps/api && npm run check && npm run smoke`
- `cd apps/web && npm run check:inactivity`

## Build

```powershell
cd apps\desktop
npm install
npm run check
npm run dist
```

The installed version should be **1.0.13**. Build the Windows desktop installer; Railway/Vercel runtime code has not changed.

## Staging verification (important)

1. Join as host with two PIN viewers; speak continuously for at least 15 minutes, including >160 lines.
2. Verify new captions follow the bottom without touching the scrollbar. Scroll up deliberately and verify text stays where you put it; scroll to the bottom to resume following.
3. Verify interim-to-final transitions do not remove visible words, and the window does not flash while the cursor hovers.
4. Verify group chat, English (UK), technologies (Kubernetes, LangChain, LangGraph), End Session and PDF generation.

**Trade-off:** To guarantee text that was already displayed never changes, later Google Meet corrections to those visible words are not applied to the overlay. The unchanged canonical final caption remains available to transcript persistence. These automated tests do not establish Google Meet's end-to-end latency or fully reproduce Windows compositor behaviour; live staging validation is required.
