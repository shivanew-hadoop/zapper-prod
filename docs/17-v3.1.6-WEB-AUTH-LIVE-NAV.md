# v3.1.6 Web/Auth/Live Navigation

## Password reset production variables

Set on Railway:

- `PASSWORD_RESET_BASE_URL=https://zapper-prod.vercel.app` during Vercel-domain testing; later use `https://zapperapp.in`.
- `PASSWORD_RESET_MINUTES=30`
- `RESEND_API_KEY=<provider API key>`
- `PASSWORD_RESET_FROM=Zapper <no-reply@zapperapp.in>` after sender-domain verification.
- `PASSWORD_RESET_RETURN_LINK=false` in production. Use `true` only for controlled testing without email delivery.

Forgot Password always returns a generic response so unregistered emails cannot be enumerated. Admins may directly set a replacement password from the user management panel.

## Desktop live-session navigation

Google Sign-In may be opened while a meeting is active. The active live panel is preserved. A Back to Live control appears only if an active session token exists while the join panel is visible.
