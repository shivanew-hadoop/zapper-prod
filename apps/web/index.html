FEATURES

Everything needed for a controlled transcription workflow.

Participant simplicity on one side; host accountability and transcript history on the other.

PIN

Session PINs

Every host-created Meet session receives a unique six-digit PIN stored against that host and meeting.

LIVE

Desktop transcription

The participant enters only the PIN. Zapper resolves the Meet URL and starts the existing transcription flow.

PDF

Stored PDF record

On Leave, the full transcript is saved to the host account and stored as a downloadable PDF.

15

Controlled retention

Only the latest fifteen host sessions and transcripts are retained per account to keep the database lightweight.

ADM

Admin controls

Administrators can view users, activity, subscription start/end dates, and shorten or extend access.

₹

Simple host plan

Host subscription status is checked before session creation and again when a participant redeems the PIN.

HOW TO USE

Two people, two simple responsibilities.

01

Host registers

Create a Zapper host account. An active subscription is required to create sessions.

02

Host creates session

Paste the Google Meet URL or meeting ID. Zapper stores it and returns a 6-digit PIN.

03

Participant launches Zapper

No portal login. Google Sign-In happens only inside the desktop app if required.

04

Participant enters PIN

The backend validates the host subscription and returns the matching Meet URL to the desktop.

05

Meeting is transcribed

Live captions continue through the existing private overlay and transcription service.

06

Host gets the PDF

When the participant leaves, the complete transcript is stored and appears in the host portal.

ABOUT ZAPPER

Built around a private desktop transcription workflow.

Zapper separates the commercial host account from the participant desktop experience. The website manages subscriptions, meeting sessions, PINs and transcript history. The desktop app focuses only on Google authentication, PIN redemption and live transcription.
