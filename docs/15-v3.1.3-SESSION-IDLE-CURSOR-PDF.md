# v3.1.3 focused behavior

## Session state
`active=1` means a PIN is redeemable. Host End Session, participant Leave, idle timeout, expiry, or superseding the same Meet sets `active=0`.

## Idle timeout
After a participant redeems a PIN, 20 minutes without detected speech ends the session. Set `SESSION_IDLE_TIMEOUT_MINUTES` to change it.

## Private cursor / resizing
The native OS cursor is hidden while it is over the overlay and a protected renderer pointer is shown locally. Native Windows resize borders are disabled and replaced with protected renderer resize hit-zones, preventing native horizontal/diagonal resize cursors from being exposed at overlay edges.

## PDF pause timestamps
The overlay transcript stays unchanged. Final transcript lines are timestamped locally. PDF generation inserts a 24-hour IST marker after gaps of at least `PDF_PAUSE_TIMESTAMP_SECONDS` (default 30).
