# Zapper v3.1.6

Focused update on top of v3.1.5.

- Google Sign-In no longer navigates an in-progress desktop session back to Start Session.
- Added Back to Live recovery control when a valid participant session is still active.
- Public Launch Zapper and Download Zapper remain available without website login.
- Reworked public marketing copy around low-latency captions, voice-to-text, private overlay/pointer behavior, two-way chat and one-click transcript access.
- Removed retention/admin implementation details from public feature marketing.
- Persistent site navigation/footer remains available around host/admin portal flow.
- Added public Terms, Privacy, Billing & Cancellation, Refund and Contact pages for payment-provider review.
- Added Forgot Password / reset-link flow for host and admin logins.
- Added admin-set password capability for any managed user.
- Existing host-controlled session lifecycle, PIN, STT, transcript/PDF and subscription logic retained.
